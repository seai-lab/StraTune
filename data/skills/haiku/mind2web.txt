## TASK DECOMPOSITION STRATEGY
Break every task into ordered sub-goals before acting. Common patterns:
- **Search tasks**: navigate to search → type query → submit → apply filters → sort/select result
- **Booking/form tasks**: select service tab → enter origin/location → enter destination → set dates → submit → apply filters
- **Alert/notification tasks**: search for item → find item page → locate alert/notify option → enter contact info → confirm
- **View information tasks**: search for item → navigate to item page → locate specific section/element

Complete sub-goals in order. Do NOT skip ahead or repeat completed steps.

## HOW TO INTERPRET CANDIDATE ELEMENTS
- Match element labels, placeholders, and text to the CURRENT sub-goal (not the overall task).
- WRONG: clicking a "Submit" button when the search field hasn't been filled yet.
- RIGHT: TYPE into the search/input field first, then CLICK submit.
- When multiple elements seem relevant, prefer the one most directly tied to the UNFULFILLED part of the task.
- Ignore navigation bars, ads, and unrelated links unless they are necessary to reach the target.
- With 20 candidates, many are distractors — only act on elements directly relevant to the current step.

## ACTION TYPE RULES
- **TYPE [id] [value]**: Use for text input fields (search boxes, email fields, location fields). Use the EXACT value specified in the task (e.g., airport codes, city names, email addresses).
- **SELECT [id] [value]**: Use for dropdown menus (sort order, car type, date selectors). Match the dropdown option text as closely as possible to the task requirement.
- **CLICK [id]**: Use for buttons, links, checkboxes, and tabs. Use when no value needs to be entered.

Concrete examples:
- `ACTION: CLICK [3]`
- `ACTION: TYPE [5] New York`
- `ACTION: SELECT [7] Price: Low to High`

- **Airline sites (e.g., American Airlines)**: Flight alert/notification features are often on the flight search results page. Look for "Flight Alerts," "Notify Me," "Price Alerts," or email subscription options. Airport code fields accept 3-letter IATA codes (e.g., BHZ, EWN).

- **Train/transit (e.g., Amtrak)**: Fill origin and destination fields → submit search → use sort dropdown on results page (look for "Shortest Trip" or "Duration").

- **General**: Site-specific terminology may differ from the task description. Look for semantically equivalent labels.

## HANDLING AMBIGUITY AND EDGE CASES
- When an autocomplete dropdown appears after typing, CLICK the matching suggestion rather than typing further.
- When a date picker appears, use CLICK or SELECT to set the correct date — do not type into a read-only date field.
- If the target information is already visible on the page (e.g., a rating, a schedule), CLICK the element displaying that information as the final step.
- If an expected element isn't visible, look for intermediate steps: confirmation dialogs, "Next" buttons, or page tabs that need to be activated first.
- When the task says "view" something, the final step is typically CLICKing the element that displays the answer.
